## 🚀 Concept Overview

"Techfest — The Future in Motion" reimagines the digital presence of Asia's largest science and technology festival with a bright, premium, editorial aesthetic. Combining high-impact typography, curated 2D photographic compositions, and structured content hierarchy, the landing page provides a seamless discovery experience across competitive arenas, technical workshops, and community initiatives.

## 📐 Section Architecture

1. **Section 1 — Premium Header:** Sticky translucent navigation bar with section scroll spy, mobile slide-out drawer, quick links, and direct portal reference.
2. **Section 2 — Hero Section:** *"Where Innovation Meets Imagination"* with layered 2D photographic compositions, abstract engineering lines, and primary CTAs.
3. **Section 3 — About the Festival:** *"More Than a Festival. A Platform for Ideas"* highlighting Technology, Scientific Exploration, Innovation, Learning, Collaboration, and Student Participation.
4. **Section 4 — Explore the Competitions:** *"Challenge What's Possible"* featuring multi-category filtering (Robotics, AI, Coding, Engineering, Innovation, Science), real-time search, and interactive modal views.
5. **Section 5 — Workshops and Learning:** *"Learn. Experiment. Build."* showcasing bootcamps across Generative AI, Data Science, Embedded IoT, Cloud/Cyber Defense, and Product Design.
6. **Section 6 — Technology and Innovation Showcase:** *"Ideas That Shape Tomorrow"* presenting an editorial visual gallery of cutting-edge exhibits from robotics to planetary exploration.
7. **Section 7 — Why Participate?:** *"Your Next Opportunity Starts Here"* articulating 6 core growth pillars for student participants.
8. **Section 8 — Community and Initiatives:** *"Innovation with a Purpose"* highlighting the Ignite technical club accreditation, Campus Ambassador network, and sustainability campaigns.
9. **Section 9 — Final Call to Action:** *"The Future is Waiting. Make Your Move."* with dual discovery actions.
10. **Section 10 — Professional Footer:** Complete navigation, back-to-top button, creator attribution, and clear student project disclosure.

## 🛠️ Tech Stack

- **Framework:** React 18 with TypeScript
- **Bundler:** Vite 5
- **Styling:** Tailwind CSS with custom editorial design tokens
- **Icons:** Lucide React
- **Dependencies:** Lightweight, zero 3D overhead, fast initial load and responsive layout.

---

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start Vite local development server
npm run dev

# Build production bundle
npm run build
```
